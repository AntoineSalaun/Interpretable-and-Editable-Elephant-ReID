\paragraph{Single-concept identity prediction.}
To measure the independent identity information carried by each concept group, we first apply the correction policy to the full SEEK code at each correction level. Gallery concepts are corrected with the sighting-level policy \(sighting\_p\), while query concepts are corrected with the image-level policy \(image\_p\). We then merge the SEEK attributes into eight higher-level groups: sex, age, tusks, tear 1, tear 2, hole 1, hole 2, and extreme/special features. For each group and correction level, we train a linear softmax logistic classifier from the concatenated one-hot attributes in that group to identity. Bars report top-1 identity accuracy on the query split. This isolates whether a high-level visual concept group is linearly informative about identity without access to the rest of the SEEK code.
