\paragraph{Leave-one-concept-out information.}
To estimate each concept group's combinatorial contribution, we first apply the correction policy to the full SEEK code at each correction level. Gallery concepts are corrected with the sighting-level policy \(sighting\_p\), while query concepts are corrected with the image-level policy \(image\_p\). We then concatenate the eight grouped SEEK concept blocks and train a linear softmax logistic classifier from this representation to identity. For each ablation, all concept groups start from the same globally corrected code; we remove only the group being tested and retrain the same classifier while keeping all remaining groups available. The reported score is the combinatorial accuracy gain from including the group, computed as the query identity accuracy of the full classifier minus the accuracy of the ablated classifier. Large positive gains indicate high-level concept groups that provide nonredundant identity information beyond the rest of the SEEK code.
