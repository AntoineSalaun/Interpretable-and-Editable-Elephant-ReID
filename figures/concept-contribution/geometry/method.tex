\paragraph{Concept geometry.}
For each correction level \(p \in \{25,50,75,100\}\), we restore the corresponding SEEK-CBM projector checkpoint and recompute gallery embeddings with deterministic ordering. Gallery interventions are applied to the full SEEK code at sighting level: all images from a sampled fraction \(p\) of sightings receive the sighting-level SEEK code for all attributes, while the remaining images use the hard concept-head prediction. We then merge the SEEK attributes into eight higher-level groups: sex, age, tusks, tear 1, tear 2, hole 1, hole 2, and extreme/special features. For every group, we group gallery embeddings by the edited categorical tuple for that group and report the pair-weighted mean within-group cosine distance. For large groups, distances are estimated by uniformly sampling image pairs within each concept-group value. Lower values indicate that samples sharing the same high-level concept value occupy a tighter region of the joint embedding space.
